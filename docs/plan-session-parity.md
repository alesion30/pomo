## pomo-9：タイマーまわりとウィンドウ

- [ ] メニューバーの書式を `タイトル - 時間` にする。超過中は `タイトル - +03:12`、タイトルが空なら時間だけ。休憩中は今の `☕ 03:10` のまま。タイトルは全角 12 文字で切り詰める（`src-tauri/src/schedule.rs` の `format_title`）。
- [ ] 集中中の「休憩」と「終了」は、予定時間の前だけ確認を出す。確認は破棄と同じく、ウィンドウの中央に重ねる。予定時間の後は確認なしで実行する。
- [ ] −5 分で残りが 5 分未満になる場合は、予定時間を経過時間までにして、すぐ超過にする。休憩も同じ。予定時間に到達したので、集中は `completed` に数える。残りが 5 分以上なら、今までどおり予定時間を 5 分減らし、下限は 5 分のまま。
- [ ] ±5 分の操作で予定時刻を過ぎた場合は、区切りの前面化と通知を出さない。時間が進んで予定時刻を過ぎた場合だけ出す（`DueTracker`）。ウィンドウの中身は、超過中の画面（集中終了時、休憩終了時の画面）に切り替わる。
- [ ] メインウィンドウはいつも最前面（フローティングの階層）に出す。他のアプリの全画面表示のスペースには出さない。区切りの間だけ今までどおり全画面表示の上に出し、区切りを抜けたらフローティングの階層に戻す。切り替えの設定は作らない。

検証：`pnpm lint`、`pnpm typecheck`、`pnpm test`、`cargo clippy`、`cargo test`、`pnpm e2e`。実機では、−5 分で超過に入っても前面化と通知が出ないこと、他のアプリを前面にしてもメインウィンドウが上に残ること、区切りを抜けた後も最前面のままであることを確かめる。

## pomo-10：休憩中の画面

- [ ] 休憩中のボタンを「集中を開始」と「休憩を破棄」にする。「休憩を終了」はなくす。
  - 「集中を開始」は、休憩をその時点までで記録し、すぐ次の集中を始める。
  - 「休憩を破棄」は確認を出し、休憩を記録せずに待機に戻る。連続の回数と、直前のフェーズの終了時刻は変えない。
- [ ] 休憩中と休憩終了時の画面で、次の集中のタイトルとカテゴリを入れる。振り返りの欄は出さない。

## pomo-11：設定ファイル、設定画面、カテゴリの選択式

- [ ] 設定ファイルを `$XDG_CONFIG_HOME/pomo/config.json`、未設定なら `~/.config/pomo/config.json` に置く。形式は `{"categories": [...]}`。手で編集してよい。
  - ファイルがなければ、起動時に `{"categories": []}` で作る。
  - ウィンドウが前面に来たときに読み直す。壊れていたら前に読めた内容を使い続け、設定画面にエラーを出す。
- [ ] カテゴリを選択式にする。選択肢は「なし」と `config.json` の内容だけ。過去のログから候補は作らない。待機中、集中中、休憩中で同じ部品を使う。
  - 一覧にないカテゴリが進行中の集中に付いていれば、名前だけを出して記録にもそのまま使う。注記は付けない。入力欄に残っているだけのものは「なし」に戻す。
- [ ] メインウィンドウの中に設定画面を作る。右上の歯車、⌘,、メニューバーのメニューから開く。タイマーが進んでいる間も開け、区切りが来たら区切り画面を優先する。
  - カテゴリの追加、名前の変更、削除、並べ替え。
  - 「設定ファイルを Finder で表示」。
  - 今のバージョンと「アップデートを確認」。適用は待機中だけ。
- [ ] 右下の「更新あり」の表示は残す。
- [ ] `docs/spec.md` の「作らないもの」から「設定画面」を外す。
